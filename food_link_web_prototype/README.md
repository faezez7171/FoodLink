# Food Link — نمونه اولیه وب فارسی
برای مشاهده، فایل `index.html` را مستقیماً با مرورگر باز کنید؛ وب‌سرور لازم نیست.

صفحات مستقل: index/login، داشبورد، سفارش‌ها، ثبت سفارش، جزئیات سفارش، محصولات، مشتریان، انبار، ارسال و تحویل، گزارش‌ها، کاربران و تنظیمات.

ویژگی‌ها: RTL فارسی، طراحی واکنش‌گرا، منوی موبایل، پوسته روشن/تیره، پیمایش بین صفحات، داده‌های نمونه، فیلتر سفارش‌ها و ثبت سفارش آزمایشی. داده‌های تعاملی در localStorage همان مرورگر ذخیره می‌شوند.

محدودیت: این یک پروتوتایپ فرانت‌اند است، نه سامانه عملیاتی. احراز هویت، نقش‌ها، API، پایگاه داده، صدور فاکتور و کنترل موجودی واقعی پیاده‌سازی نشده‌اند. برای استفاده واقعی به بک‌اند و امنیت سمت سرور نیاز است.

فایل‌های مشترک ظاهری و رفتاری در `assets/style.css` و `assets/app.js` قرار دارند؛ هر صفحه HTML مستقل و قابل بازشدن مستقیم است.
