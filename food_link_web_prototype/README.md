# Food Link — نسخه دوم نمونه اولیه وب

## اجرا
فایل `index.html` را مستقیماً با مرورگر باز کنید. برای مشاهده صفحات به وب‌سرور نیاز نیست. فونت Vazirmatn در صورت دسترسی اینترنت از Google Fonts دریافت می‌شود؛ در حالت آفلاین فونت جایگزین سیستم نمایش داده خواهد شد.

## پنل‌ها و صفحات
- ورود و انتخاب نقش: `index.html`
- پنل مدیریت: `dashboard.html`
- پنل مشتری: `customer-panel.html` و `customer-catalog.html`
- پنل بازاریاب: `marketer-panel.html`
- پنل انباردار: `warehouse.html`
- سفارش‌ها و جزئیات/گردش سفارش: `orders.html` و `order-detail.html`
- ثبت سفارش: `new-order.html`
- محصولات: `products.html`
- مشتریان و محدودیت نمایش قیمت/تخفیف: `customers.html`
- پروفایل قیمت: `price-profile.html`
- ارسال و تحویل: `deliveries.html`
- گزارش‌ها، کاربران و تنظیمات: `reports.html`، `users.html`، `settings.html`

## قابلیت‌های نمونه
- پنل‌های رنگ‌بندی‌شده برای مدیر، مشتری، بازاریاب و انباردار
- ثبت سفارش چندقلمی با محاسبه خودکار جمع کل
- تاریخ تحویل با ورودی متنی شمسی و مقدار پیش‌فرض تاریخ روز شمسی
- ثبت و افزودن محصول و مشتری
- کنترل نمایشی مخفی‌سازی قیمت و تخفیف برای مشتری
- تاریخچه قیمت و ثبت قیمت/تخفیف جدید
- گردش وضعیت سفارش: ثبت، تأیید، آماده‌سازی، آماده ارسال، تحویل کامل/جزئی/ناموفق یا رد
- گزارش نمونه عملکرد بازاریاب و فروش کالاها
- دعوت نمایشی کاربر و ثبت نقش و صفحات مجاز
- حالت روشن/تیره، RTL و طراحی واکنش‌گرا
- نگهداری داده‌های نمونه در localStorage مرورگر

## نکات مهم
این پروژه صرفاً پروتوتایپ فرانت‌اند است. ورود، نقش‌ها، محدودیت نمایش قیمت، دعوت کاربران و دسترسی صفحات در این نسخه امنیت واقعی سمت سرور ندارند و صرفاً برای نمایش جریان کار هستند. برای نسخه عملیاتی باید احراز هویت، مجوزدهی سمت سرور، API و پایگاه داده پیاده‌سازی شود. همچنین تاریخ شمسی فعلی به‌صورت فیلد متنی با مقدار پیش‌فرض شمسی است و هنوز تقویم گرافیکی کامل (انتخاب ماه/روز با شبکه تقویم) نیست.

داده‌ها در حافظه محلی همان مرورگر ذخیره می‌شوند؛ پاک‌کردن داده‌های سایت، آن‌ها را حذف می‌کند.
